# SMS Forwarder

یک برنامه Android ساده و قدرتمند که SMS های دریافتی را با شرایط تعریف شده توسط کاربر فیلتر می‌کند و در صورت تطابق، محتوای SMS را به صورت خودکار به یک وب‌هوک (Webhook) ارسال می‌کند.

## ✨ ویژگی‌ها

- ✅ **فیلتر هوشمند SMS**: دریافت و پردازش خودکار SMS های دریافتی
- ✅ **شرایط چندگانه**: امکان تعریف چندین شرط فیلتر با منطق OR
- ✅ **فیلتر بر اساس شماره**: فیلتر بر اساس شماره فرستنده (شامل یا دقیق)
- ✅ **فیلتر بر اساس متن**: فیلتر بر اساس محتوای پیام
- ✅ **ارسال خودکار HTTP POST**: ارسال خودکار به وب‌هوک با JSON payload
- ✅ **رابط کاربری زیبا**: طراحی مدرن با پشتیبانی از Dark Mode
- ✅ **مدیریت شرایط**: افزودن، ویرایش و حذف آسان شرایط
- ✅ **فعال/غیرفعال کردن**: کنترل کامل بر عملکرد برنامه

## 📋 پیش‌نیازها

- Android SDK (حداقل نسخه 24)
- Android Studio یا Gradle
- Java 17 یا بالاتر

## 🚀 نصب و راه‌اندازی

### 1. کلون کردن پروژه

```bash
git clone https://github.com/yourusername/smsforwarder.git
cd smsforwarder
```

### 2. تنظیم Android SDK

فایل `local.properties` را در ریشه پروژه ایجاد کنید:

```bash
echo "sdk.dir=/path/to/your/android/sdk" > local.properties
```

**نکته**: مسیر SDK معمولاً در سیستم‌عامل‌های مختلف:
- **Linux**: `$HOME/Android/Sdk`
- **macOS**: `$HOME/Library/Android/sdk`
- **Windows**: `%LOCALAPPDATA%\Android\Sdk`

### 3. ساخت APK

```bash
./gradlew assembleDebug
```

APK در مسیر زیر ساخته می‌شود:
```
build/outputs/apk/debug/smsforwarder-debug.apk
```

برای ساخت نسخه Release:
```bash
./gradlew assembleRelease
```

## 📱 نحوه استفاده

### 1. نصب برنامه

```bash
adb install build/outputs/apk/debug/smsforwarder-debug.apk
```

یا فایل APK را به صورت دستی روی دستگاه Android نصب کنید.

### 2. تنظیمات اولیه

1. برنامه را باز کنید
2. **مجوزهای SMS را اعطا کنید** (برای عملکرد برنامه ضروری است)
3. **آدرس وب‌هوک** را وارد کنید (مثال: `https://api.example.com/webhook`)
4. **هدرهای سفارشی (اختیاری)** را وارد کنید (فرمت JSON):
   - مثال: `{"Authorization": "Bearer token123", "X-Custom-Header": "value"}`
   - این فیلد اختیاری است و می‌توانید خالی بگذارید
5. **شرایط فیلتر** را اضافه کنید:
   - روی دکمه "افزودن شرط جدید" کلیک کنید
   - نام شرط را وارد کنید (اختیاری)
   - حداقل یکی از فیلدهای زیر را پر کنید:
     - **شماره فرستنده (شامل)**: اگر شماره شامل این متن باشد
     - **شماره فرستنده (دقیق)**: اگر شماره دقیقاً این باشد
     - **متن پیام (شامل)**: اگر متن پیام شامل این کلمه/متن باشد
6. روی "ذخیره تنظیمات" کلیک کنید
7. برنامه را با دکمه "فعال کردن برنامه" فعال کنید

### 3. منطق فیلتر

- **منطق OR**: اگر **هر کدام** از شرط‌ها تطابق داشته باشد، SMS ارسال می‌شود
- می‌توانید چندین شرط تعریف کنید
- هر شرط می‌تواند شامل چندین فیلتر باشد (شماره + متن)

### 4. فرمت درخواست HTTP POST

وقتی SMS با شرایط تطابق داشته باشد، یک درخواست POST به آدرس وب‌هوک شما ارسال می‌شود:

**URL**: آدرس وارد شده در تنظیمات

**Headers**:
```
Content-Type: application/json
[هدرهای سفارشی که در تنظیمات وارد کرده‌اید]
```

**نکته**: می‌توانید هدرهای سفارشی را در تنظیمات به صورت JSON وارد کنید. این هدرها به همراه `Content-Type` به درخواست اضافه می‌شوند.

**Body (JSON)**:
```json
{
  "text": "متن کامل SMS دریافتی",
  "timestamp": 1234567890123,
  "from": "09123456789"
}
```

## 📝 مثال‌های استفاده

### مثال 1: فیلتر بر اساس شماره فرستنده

```
نام شرط: بانک
شماره فرستنده (شامل): 0912
```

نتیجه: هر SMS که از شماره‌ای شامل `0912` دریافت شود، ارسال می‌شود.

### مثال 2: فیلتر بر اساس متن

```
نام شرط: کد تایید
متن پیام (شامل): کد
```

نتیجه: هر SMS که شامل کلمه `کد` باشد، ارسال می‌شود.

### مثال 3: ترکیب شرایط

```
نام شرط: تایید بانک
شماره فرستنده (دقیق): 09123456789
متن پیام (شامل): تایید
```

نتیجه: فقط SMS هایی که از شماره دقیق `09123456789` آمده و شامل کلمه `تایید` باشند، ارسال می‌شوند.

## 🔐 مجوزهای مورد نیاز

- `RECEIVE_SMS`: برای دریافت SMS هنگام ورود پیام جدید
- `INTERNET`: برای ارسال درخواست HTTP
- `ACCESS_NETWORK_STATE`: برای بررسی وضعیت شبکه

## 🐛 عیب‌یابی

### برنامه SMS ها را دریافت نمی‌کند

1. مطمئن شوید مجوزهای SMS اعطا شده است
2. بررسی کنید که برنامه فعال است
3. بررسی کنید که حداقل یک شرط تعریف شده است

### درخواست HTTP ارسال نمی‌شود

1. بررسی کنید آدرس وب‌هوک معتبر است
2. بررسی کنید دستگاه به اینترنت متصل است
3. لاگ‌های برنامه را بررسی کنید (Logcat)

### مشاهده لاگ‌ها

```bash
adb logcat | grep -E "SmsReceiver|HttpService"
```
